# SQL Use Cases – Retail Sales Assessment

## Overview
This project was completed as part of a SQL assessment using retail sales data. It covers data cleaning, combining data from multiple tables, querying, and business analysis.

## Tools Used
- MySQL Server 8.0
- MySQL Workbench 8.0

## Work Completed
- Region mapping and data validation
- Duplicate record identification and handling
- Table relationships and ER diagram
- SQL joins
- Identification of unmatched records
- Customer and return analysis
- Regional and store-level sales analysis
- Gross sales, return value, and net sales calculations

## Business Analysis
The October 2026 analysis compares regional and store-level sales, returns, and net sales. It also identifies the region with the highest sales and returns, top-performing stores, and product categories contributing to returns.

## Repository Contents
- Completed worksheet
- SQL scripts arranged in question order
- Query output screenshots
- ER diagram
- One-slide PowerPoint business summary
